# HALDEN STARWIND

Premium hybrid Hall reverb and atmospheric spatial processor for macOS (AU/VST3).

## Status

Project foundation is being established. The initial implementation will use C++ and JUCE with CMake, targeting macOS.

## Product identity

- Balanced, airy, deep Hall character
- BREEZE: subtle evolving modulation
- STARDUST: restrained spectral shimmer
- SILK TAIL: smooth, dense decay
- INFINITE and FREEZE modes

## Planned signal path

Input → De-Esser → Chorus → Hybrid Hall → Starwind Engine → Post EQ → Output
